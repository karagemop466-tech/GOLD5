Bottom line

No listing proved on its own page that it is solid, correctly stamped gold. Treat every row as a lead to verify: get the weight in grams, “solid gold” and stamp confirmation in writing, read the return policy for resize/custom exclusions, pay by credit card, and have an independent jeweler run XRF testing before wearing or resizing. If the seller won’t allow independent verification or return — don’t buy.
