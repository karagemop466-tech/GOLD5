How to read this table

  • Blank — unverified means the seller’s page did not state that value (or it could not be confirmed). It is never filled in. See Flagged for Review.
  • Gold value @ spot (calculated) = weight (g) × Kitco spot per gram ($129.41/g from $4,025.00/oz, 2026-10-22) × karat ÷ 24. Only shown when the listing states both weight and karat. It is melt value of the gold only — stones, labor and retail margin are not included.
  • Price ÷ gold value is only meaningful for setting-only rows. Rows that include diamonds also pay for the stones.
  • Weights marked “Approximate” are the seller’s own approximations; confirm on a scale after delivery.
