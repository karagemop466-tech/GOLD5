What to keep

Document Why keep it Source
The listing Keep the product listing as the seller described it. Checklist requirement (consumer guidance)
The receipt Keep the receipt showing what you paid, from whom, and when. Checklist requirement (consumer guidance)
The description Keep the item description (weight, karat, dimensions, stones). Checklist requirement (consumer guidance)
Seller's purity claims Keep the seller's claims about the gold's purity (10K/14K/18K statements, stamps, certificates). Checklist requirement (consumer guidance)
Return policy (in writing) Get the store's refund and return policies in writing before you buy. FTC — Before You Buy
Dated receipt / contract with seller name and address For sales covered by the FTC Cooling-Off Rule, the receipt or contract must be dated and show the seller's name and address. FTC — Cooling-Off Rule

If something goes wrong

  • Try to resolve the problem with the seller first.
  • If not satisfied, report to the FTC at ReportFraud.ftc.gov, to your state attorney general, and/or to the Jewelers Vigilance Committee (JVC) mediation program.
  • Sources: FTC — Report Problems · NAAG — State Attorneys General
No templates invented. No sample documents or letter templates appear on this site; none were verified from an official source, so none were created. Keep your own copies of everything listed above.
