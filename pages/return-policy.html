Return Policy

Make sure you can return the ring after receiving and inspecting it. Check specifically for exclusions on resized or custom rings.

Check Action Source Verified Source Link
Return window Find the store's refund and return policies — get them in writing Verified FTC Consumer Guide
Resized/custom exclusions Check specifically for exclusions on resized or custom rings Verified FTC Consumer Guide
Inspection period Ensure you can return after receiving and inspecting the ring Verified FTC Consumer Guide

What to Check

  • Get the return policy in writing before purchasing
  • Check for time limits on returns (e.g., 30 days, 60 days)
  • Check whether resized rings are excluded from returns
  • Check whether custom/engraved rings are excluded from returns
  • If the seller won't accept returns, don't buy
