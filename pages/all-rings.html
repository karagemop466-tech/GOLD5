How to read this table

  • Karat is copied from the listing's metal field. It is the seller's claim, not a test result.
  • “Solid gold” wording is “Explicit” only when the page uses the phrase. A karat alone does not exclude plating or vermeil.
  • Weight is shown only when the seller published grams. Two rows do; the other ten are blank and flagged (F-004).
  • Fine-gold value at spot is grams × karat/24 × $4,028.10/oz ÷ 31.1034768. It is melt value, not resale value, and it needs a weight — so it is empty here.
  • Flags link to the Flagged for review page with the source and the recommended action.
