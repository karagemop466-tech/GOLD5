XRF Testing — Professional Gold Purity Verification

Ask for XRF testing or another professional gold-purity test. Don't rely solely on the stamp. XRF (X-ray fluorescence) is a non-destructive test that verifies gold purity.

Test Method Description Destructive? Source Verified Source Link
XRF testing X-ray fluorescence — non-destructive analysis of metal composition No Verified FTC Consumer Guide
Fire assay Traditional method for precise gold content determination Yes (sample destroyed) Verified FTC Consumer Guide
Stamp only Relying on the karat stamp alone — NOT sufficient proof N/A Verified FTC Consumer Guide

Best Practices

  • Ask for XRF testing before finalizing the purchase, if possible
  • After delivery, take to an independent jeweler for XRF testing
  • Compare test results against the seller's documented claims
  • If the seller won't allow independent verification, don't buy
  • XRF is non-destructive and safe for finished jewelry

Source: FTC — Buying Platinum, Gold, and Silver Jewelry
