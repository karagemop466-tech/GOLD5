Method & passes

How the no-hallucination rule is enforced mechanically, and what this project still cannot tell you.

The rule

NO HALLUCINATIONS. Every value on this site was read from the linked official page and is stored with the exact text that was on that page (verification/evidence/*.txt). If a value could not be confirmed, the cell is blank and the row is flagged. Nothing is estimated, converted, or filled in.

Practically: a value is written down only if it was read off the seller's own page (or an official regulator's page) at a known time, and the exact text is saved in this repository. Derived numbers are never typed — the builder computes them and the checker recomputes them independently.

How verification works here

CheckWhat it does
Evidence matchFor every row, each recorded value must appear verbatim in the saved capture of that page (a "token"). A number that is not in the capture fails the build.
ArithmeticFine gold, metal value, troy ounces, price-per-gram and the price ÷ metal multiple are recomputed from the raw inputs by the checker and compared with what the site renders.
Domain allowlistEvery link in the dataset must belong to a seller's real domain or an official body (FTC, eCFR/Cornell LII, BBB, Etsy Help, Kitco). A link to an unknown domain fails.
Money auditEvery dollar amount that appears in the generated HTML must trace back to a seller's published price, a reference quote, or a recomputed value. A hand-typed price fails.
Link integrityEvery internal link and anchor on every page must resolve to a file or id in the built site.
Flag cross-referenceEvery flag referenced by a row must exist, and every listing id a flag mentions must exist.

Run it yourself: python3 tools/check_report.py. It prints a per-check summary and exits non-zero on failure. The pass log below is generated from the run.

Limitations you should hold in mind

  • Stamps cannot be seen online. No seller in this catalogue publishes a hallmark photo. The FTC's own advice — don't buy gold jewellery without a maker's mark next to the karat — can only be satisfied in person.
  • Weights are mostly unpublished. 19 of 27 rows have no seller-published weight, so their gold value is unknown, not zero.
  • Prices are snapshots. Etsy listings carry timed promotions ("25% off · Limited time sale"); the recorded figure is what the page showed at capture.
  • Reputation is thin. Only two sellers have an independent source verified here; the rest are blank rather than assumed.
  • No currency conversion, ever. When Brilliant Earth served the 18K page in euros, the USD cell was left blank.
  • Not financial or legal advice. Verify with an independent jeweler, ask for XRF, and keep the paperwork.
