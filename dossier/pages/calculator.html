⚠ NO HALLUCINATED PRICES — the governing rule of this project

  • Nothing here is estimated, remembered or inferred. Every price, karat claim, metal description and gram weight was read from an official first-party page (the retailer's own product page, the marketplace's own item page, or the benchmark administrator's own site) and stored with three things: the source URL, a UTC capture timestamp, and the literal verbatim excerpt that contains the number.
  • If a value could not be confirmed, the cell is left blank and the row is published on Flagged for review. A blank cell is a deliberate, honest result — never a gap filled by guesswork.
  • Automated anti-hallucination checks run at every build. Current run: 18/18 PASS, 0 FAIL. Check C3 re-parses every published price out of its own evidence excerpt and fails the build if the number is not literally there. Check C6 does the same for gram weights. See Verification.
  • Prices move. Retail jewellery prices and the gold price both change constantly, so every value is a timestamped observation, not a standing quote. Re-read the live page before paying — this dataset contains two documented cases where the same official page was indexed at two different prices (F-05, F-06).

How to read the result

  • Intrinsic gold value is not what a ring is worth. It is the melt value of the alloy's gold content only. It excludes labour, design, brand, the centre stone, the accent stones, certification and retail margin.
  • A finished ring normally costs several times its gold content. The multiple is informative, not a verdict.
  • The dangerous direction is too cheap. If the asking price is at or below the intrinsic gold value of the claimed weight and karat, the metal claim, the weight claim or the seller's honesty is wrong. That is the checklist's "unusually cheap price is a red flag" test, expressed arithmetically.
  • Scrap buyers pay less than spot. Refiners and pawn shops discount for melting, assay and margin, so this figure is a ceiling for scrap purposes, not an offer you will receive.
  • The stamp does not prove purity. Only an independent test (XRF or fire assay) does — see Checklist and Flagged for review (F-02).
