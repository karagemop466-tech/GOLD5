⚠ NO HALLUCINATED PRICES — the governing rule of this project

  • Nothing here is estimated, remembered or inferred. Every price, karat claim, metal description and gram weight was read from an official first-party page (the retailer's own product page, the marketplace's own item page, or the benchmark administrator's own site) and stored with three things: the source URL, a UTC capture timestamp, and the literal verbatim excerpt that contains the number.
  • If a value could not be confirmed, the cell is left blank and the row is published on Flagged for review. A blank cell is a deliberate, honest result — never a gap filled by guesswork.
  • Automated anti-hallucination checks run at every build. Current run: 15/15 PASS, 0 FAIL. Check C3 re-parses every published price out of its own evidence excerpt and fails the build if the number is not literally there. Check C6 does the same for gram weights. See Verification.
  • Prices move. Retail jewellery prices and the gold price both change constantly, so every value is a timestamped observation, not a standing quote. Re-read the live page before paying — this dataset contains two documented cases where the same official page was indexed at two different prices (F-05, F-06).

Why there is no single "current gold price" in this dataset

The LBMA Gold Price is the internationally recognised benchmark, administered by ICE Benchmark Administration (IBA) and auctioned twice daily at 10:30 and 15:00 London time. The LBMA page was fetched live during this session and states that the historical tabulated data has moved to the MyLBMA Portal and that a licence from IBA is required to obtain, use or redistribute benchmark data. Publishing an "LBMA price" number without that licence would mean publishing a figure with no admissible source — so this project does not. Instead it records what named publishers actually printed, with timestamps.

Live-verified source: https://www.lbma.org.uk/prices-and-data/lbma-precious-metal-prices — observed 2026-10-22T23:15:00Z (tier: live).

LBMA benchmark facts, verbatim from the live fetch

  • The LBMA Gold Price is set twice daily in auctions independently operated and administered by ICE Benchmark Administration Limited (IBA) and commencing at 10:30 and 15:00 London time.
  • Sterling and Euro prices are available but they are indicative prices for settlement only.
  • LBMA Precious Metal Prices are not published on either weekends or those days designated as UK bank holidays.
  • The historical tabulated data for the LBMA Precious Metals Prices has been moved to the MyLBMA Portal; a relevant licence from IBA is required to view it.
  • A licence from IBA is required in order to obtain, use or redistribute real-time or historical benchmark data.
