Browse by category

Every row appears in the same table layout as Listings, with the same source link, check date and flags. A category view never changes a value — it only filters rows. Categories overlap on purpose (an 18K solitaire appears in both), because karat, style and price basis are different questions.

What a category is — and is notA category is a grouping label taken from the seller's own product name (solitaire, halo, pavé), the stated karat, or the price basis the seller states (setting only vs complete). It is not a purity or quality claim, and it is not a ranking. No category has a “best buy”.
