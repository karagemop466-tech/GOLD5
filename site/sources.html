Source registry — what each link verifies

Complete list of official sources used, what each one backs, how it was captured (direct page fetch vs. search snippet of the official page), and the check date. This is the audit trail for the no-hallucinations rule: if a value on this site has no row here, it should not exist. Regenerated from site/assets/data.js — the same file scripts/verify.py checks.

Verification method (per project policy)

  1. A value is recorded only after being read from the source page (direct fetch) or from a search result that quotes the source page (snippet) — and the URL is recorded next to it. Snippet-captured values are labeled in the table.
  2. checkedOn date recorded for every cell group; prices are same-day (2026-10-22).
  3. Derived numbers (pure gold grams, troy oz, metal value, price ratio) are computed by browser JS / scripts/verify.py from raw inputs — never typed in.
  4. Anything not confirmable from an official source → blank + Flagged for Review.
  5. After every review: run python3 scripts/verify.py (hallucination + link + arithmetic pass) and update the log in COORDINATION.md.
