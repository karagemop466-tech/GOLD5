How every value was checked

This page is the audit trail. It lists what was fetched live in this pass, what changed as a result, and the exact command that re-checks the whole site. If you only read one page before trusting a number, read this one.

The five rules

  • Read the source page, not a snippet or another site's summary. Record the URL and the date.
  • Quote it. Every non-obvious value has the seller's exact wording stored in site/assets/data.json and in this repo's evidence files.
  • Blank beats wrong. If the page does not state a weight, price, policy or mark, the cell is null and a flag is opened.
  • Compute, don't type. Fine gold, metal value and ratios are derived by the build and re-derived by scripts/verify.py from the raw inputs and the timestamped spot.
  • Re-run after every review. The checker fails the build on a missing source link, an unsourced dollar figure, a broken internal link or an arithmetic mismatch.
